# 응원 전광판 · Cheer Board

> 케이팝 공연장에서 핸드폰으로 띄우는 무료 응원 전광판 웹앱  
> A free web-based LED cheer board for K-pop concerts — no ads, no in-app purchases.

**→ [Live Demo](https://cheer-board.vercel.app/)**

---

## 소개 · About

케이팝 팬덤에서 쓰는 전광판 앱들은 대부분 광고가 붙어 있거나, 인앱결제가 있거나, 출처가 불분명한 경우가 많습니다. 이 프로젝트는 그런 불편함 없이 누구나 바로 쓸 수 있는 웹앱입니다.

Most cheer board apps come with ads, paywalls, or sketchy origins. This is a clean, open alternative — just open and use.

- ✅ 광고 없음 · No ads
- ✅ 인앱결제 없음 · No in-app purchases
- ✅ 설치 없음, 브라우저에서 바로 실행 · No install required

## 사용법 · How to Use

1. 이름 입력란에 응원할 아이돌 이름 입력
2. 데코, 배경, 글씨 색, 효과 선택
3. `>` 버튼 누르면 전광판 가로 전환
4. 핸드폰을 들고 응원 🎉

## 로컬 실행 · Run Locally

별도 빌드 과정 없이 `index.html`을 브라우저에서 바로 열면 됩니다.

No build step required — just open `index.html` in any browser.

```bash
git clone https://github.com/your-username/cheer-board.git
cd cheer-board
open index.html
```
